# متجر GOFY للأزياء (أطفال & حريمي) - المنيا 👗👶

نسخة سريعة ومتجاوبة (Single-Page Frontend) مصممة بتقنيات Vanilla HTML5 / CSS3 / JavaScript بدون أطر عمل خارجية، متوافقة تماماً مع اللغة العربية (RTL) والأجهزة الذكية، ومجهزة للربط مع **Google Sheets** في المرحلة الثانية.

---

## 📍 النطاق الجغرافي وتهيئة الـ SEO المحلي (Local SEO)
* **الموقع الجغرافي**: محافظة المنيا (شارع ابن خصيب - بالقرب من شارع عدنان المالكي).
* **بيانات محركات البحث**: تم تضمين النطاق الجغرافي في العنوان والوصف التسويقي وبطاقات المشاركة وكود Schema.org JSON-LD لتعزيز الظهور المحلي للمتجر في مدينة المنيا مع إتاحة الشحن لكافة المحافظات.

---

## ⚙️ إعدادات المتجر المركزية (`GOFY_CONFIG`)

يتم التحكم في بيانات الهاتف والواتساب، ونمط العرض، والتقييمات، وإعدادات الربط السحابي من كائن مركزي واحد داخل [js/app.js](file:///d:/businees/GOFY/js/app.js):

```javascript
const GOFY_CONFIG = {
  merchantPhone: "01006563866",      // رقم هاتف التاجر (يغذي الفوتر والواتساب وJSON-LD)
  merchantWhatsApp: "201006563866",   // الرقم بالصيغة الدولية المخصصة لرابط wa.me
  DEMO_MODE: true,                    // تفعيل نمط العرض التجريبي (noindex, nofollow وشريط التنبيه)
  showRatings: false,                 // إخفاء/إظهار صف النجوم لجميع المنتجات (الافتراضي: معطل)
  googleSheets: {
    scriptURL: "",                    // رابط Google Apps Script في المرحلة الثانية
    isEnabled: false                  // تفعيل الإرسال السحابي لشيت جوجل
  }
};
```

## 🛠️ أبرز التحديثات المطبقة:

1. **إدارة الهاتف وJSON-LD من الكود المركزي فقط**:
   - حذف أي أرقام هواتف ثابتة من ملف HTML، وملء أرقام الهاتف وخطوط الواتساب في الفوتر، وتحديث خاصية `telephone` في كود JSON-LD تلقائياً عند تحميل الصفحة من `GOFY_CONFIG`.
2. **رسائل مخصصة لنافذة الدعم السريع (Fallback View)**:
   - عند حدوث خطأ في الاتصال بجوجل شيت: تظهر رسالة: `"حصلت مشكلة بسيطة في إرسال الطلب، أكمل طلبك بنقرة واحدة عبر واتساب"`.
   - عند تفعيل الوضع التجريبي وتعطيل شيت جوجل: تظهر رسالة الوضع التجريبي المعتادة.
3. **حماية فهرسة محركات البحث أثناء التطوير**:
   - ضبط وسم الروبوتس تلقائياً إلى `<meta name="robots" content="noindex, nofollow">` طالما `DEMO_MODE: true`.
   - إزالة وسم `meta keywords` بالكامل وفق معايير محركات البحث الحديثة.
4. **احتساب أعلى نسبة خصم ديناميكياً**:
   - استخراج وتطبيق أعلى نسبة خصم تلقائياً من قائمة المنتجات `PRODUCTS_DATA` (بناءً على السعر الفعلي والقديم) وعرضها في الشريط العلوي وشارة الهيرو والبانر الترويجي.
5. **ضبط التمييز اللغوي السليم للكميات (Proper Arabic Pluralization)**:
   - تطبيق قواعد التمييز الصحيحة: `1 قطعة`، `2 قطعتين`، و `3-10 قطع` في ملخص السعر اللحظي، كارت ملخص الطلب، ونص رسالة الواتساب.
6. **التحكم في إظهار التقييمات**:
   - إخفاء صف النجوم للمنتجات مع الاحتفاظ بقيمة التقييم في البيانات، ولا يظهر إلا عند ضبط `showRatings: true` اختيارياً.
7. **شريط تجريبي ملائم ومصغر للموبايل**:
   - تصغير حجم الخط والبادينج للشريط اللاصق في شاشات الموبايل (390px) مع إضافة هامش أمان للشريط الإعلاني لضمان عدم حدوث أي تداخل مع النصوص.
